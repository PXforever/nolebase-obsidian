# 网页工具

## 思维导图 / 可视化

1. [Markmap](https://markmap.js.org/repl) — 将 Markdown 实时渲染为思维导图，支持导出 SVG
2. [draw.io](https://app.diagrams.net/) — 免费在线流程图、架构图绘制工具
3. [Excalidraw](https://excalidraw.com/) — 手绘风格在线白板工具

## 编码 / 转换工具

1. [Base64 图片编码](https://www.strerr.com/cn/base64_encode_img.html) — 图片与 Base64 互转
2. [CyberChef](https://gchq.github.io/CyberChef/) — 强大的编码/解码/加密/数据转换工具箱
3. [JSON 格式化](https://jsonformatter.curiousconcept.com/) — JSON 格式化与校验

## 开发辅助

1. [Regex101](https://regex101.com/) — 在线正则表达式测试与调试
2. [Crontab Guru](https://crontab.guru/) — Cron 表达式可视化编辑器
3. [Shields.io](https://shields.io/) — 为项目生成徽章图标（Badge）

## 文档 / 写作

1. [Markdown 在线编辑器](https://dillinger.io/) — 实时预览的 Markdown 编辑器
2. [Smallpdf](https://smallpdf.com/cn) — PDF 压缩、合并、转换工具
3. [DeepL 翻译](https://www.deepl.com/) — 高质量 AI 翻译工具
